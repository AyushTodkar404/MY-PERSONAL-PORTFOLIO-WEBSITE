A personal engineering portfolio for **Ayush Todkar** &mdash; Computer Engineering student at Don Bosco Institute of Technology (DBIT), Mumbai, pursuing an Honors specialization in Ethical Hacking.

Designed according to **Unslop** and **Ponytail** principles: zero bloated dependencies, 60fps fluid responsiveness, high-contrast dark/light mode engine, and accessible semantic markup.

---

## 🌟 Key Highlights

- **Fluid Multi-Device Layout**: Optimized from mobile phones (320px) up to ultra-wide displays without layout breaks.
- **Dark & Light Mode**: Persistent theme engine with zero-flash rendering and smooth SVG iconography.
- **Scrollspy Navigation**: Dynamically tracks and highlights active viewport sections using native `IntersectionObserver`.
- **Zero Third-Party Bundlers**: Built entirely with pure semantic HTML5, modern CSS3 custom properties, and vanilla ES6+ JavaScript.
- **Direct Connect**: Direct WhatsApp message generator and secure contact channels.
