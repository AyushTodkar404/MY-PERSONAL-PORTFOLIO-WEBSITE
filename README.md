🌙 Theme Switching
The website includes a dark/light mode toggle. The selected theme is stored using browser localStorage, so the preference remains after refresh.
🖼️ Editable Profile Picture
The hero section includes an Edit photo button.
Users can choose an image from their device, and the selected image updates instantly. The chosen image is stored in the browser using localStorage, so it remains active in future visits on the same browser.

- WhatsApp contact form
The contact form collects the visitor’s name, email, and message, then opens WhatsApp with a pre-filled message. No backend server is required.
