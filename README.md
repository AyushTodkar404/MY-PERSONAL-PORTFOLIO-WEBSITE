🌙 Dark / Light Mode
The portfolio includes a theme switcher for dark and light modes.
The selected theme is stored in browser localStorage, so the preference remains active after refreshing or reopening the website.

🖼️ Editable Profile Picture
The hero section includes an Edit Photo button.
Visitors can select an image from their device, and the profile picture updates instantly in the browser. The selected image is saved using localStorage, so it remains available in that browser after refresh.
The uploaded image is stored locally in the visitor’s browser only. It does not upload to a server or change the repository image.

📬 Contact Form
The website includes a contact form with:
- Name
- Email
- Message
When submitted, the form prepares a pre-filled WhatsApp message for direct communication. No backend server or database is required.

🚀 Getting Started
Clone the Repository
git clone https://github.com/AyushTodkar404/ayush-todkar-portfolio.git
cd ayush-todkar-portfolio
Run Locally
This is a frontend-only project. Simply open index.html in a modern web browser.
For a smoother development experience, use the Live Server extension in Visual Studio Code.
💻 Using VS Code Live Server
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Open index.html.
4. Right-click inside the file.
5. Select Open with Live Server.
