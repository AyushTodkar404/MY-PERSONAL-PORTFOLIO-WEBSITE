Designed according to **Unslop** and **Ponytail** principles: zero bloated dependencies, 60fps fluid responsiveness, high-contrast dark/light mode engine, and accessible semantic markup.

---

## 🌟 Key Highlights

- **Fluid Multi-Device Layout**: Optimized from mobile phones (320px) up to ultra-wide displays without layout breaks.
- **Dark & Light Mode**: Persistent theme engine with zero-flash rendering and smooth SVG iconography.
- **Scrollspy Navigation**: Dynamically tracks and highlights active viewport sections using native `IntersectionObserver`.
- **Zero Third-Party Bundlers**: Built entirely with pure semantic HTML5, modern CSS3 custom properties, and vanilla ES6+ JavaScript.
- **Interactive Developer Console**: In-browser terminal widget with executable/clickable commands (`help`, `skills`, `projects`, `cloudvault`, `security`, `contact`) built with pure safe DOM (OWASP-compliant, zero unescaped input).
- **Interactive Project Filters**: Instant category filtering for Cloud & Security, Full Stack, and Systems projects.
- **1-Click Copy Email Pill**: Fast clipboard copy with instant visual verification feedback.
- **OWASP Security Hardening**: Strict Content Security Policy (CSP), anti-tabnabbing (`rel="noopener noreferrer"`), zero inline script violations, and complete subresource protection.
- **Direct Connect**: Direct WhatsApp message generator and secure contact channels.

## ✏️ How to Edit This Static Website

This website is **100% static** &mdash; no build tools, no Node.js compilation, and no framework dependencies required. Every section is directly editable in [`index.html`](index.html).

| What You Want to Edit | Where to Find It in `index.html` |
| :--- | :--- |
| **Hero (Name, Bio, Resume link)** | Search for `HERO SECTION` |
| **About Me (Bio text & CGPA stats)** | Search for `01. ABOUT ME SECTION` |
| **Technical Skills (Languages, tools)** | Search for `02. TECHNICAL SKILLS SECTION` |
| **Projects (Titles, descriptions, links)** | Search for `03. PROJECTS SECTION` |
| **Experience (Club role, dates)** | Search for `04. EXPERIENCE & LEADERSHIP` |
| **Areas of Interest** | Search for `05. AREAS OF INTEREST` |
| **Certifications & Training** | Search for `06. CERTIFICATIONS & TRAINING` |
| **Achievements & Hackathons** | Search for `07. ACHIEVEMENTS & HACKATHONS` |
| **Co-Curricular Activities** | Search for `08. CO-CURRICULAR ACTIVITIES` |
| **Education (B.E., HSC 12th, SSC 10th)** | Search for `09. EDUCATION & ACADEMICS` |
| **Contact (Email, phone, social links)** | Search for `10. CONTACT & CONNECT` |

### Updating your photo or resume:
1. **Photo**: Replace `profile-photo.jpeg` with your new photo file (keep the same filename).
2. **Resume**: Replace `Resume.pdf` with your updated PDF (keep the same filename).

### Publishing your edits to GitHub:
```bash
git add .
git commit -m "Update portfolio details"
git push origin main
```
Your live site on GitHub Pages will automatically update within 60 seconds.
